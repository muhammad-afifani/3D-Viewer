Panduan Kerja Hybrid Cloud-to-Offline (.NWD Viewer)
Mengapa Menggunakan Arsitektur Hybrid Cloud-to-Offline?
Format .nwd (Autodesk Navisworks) menggunakan kompresi biner proprietary tertutup milik Autodesk. Dengan arsitektur ini, Anda dapat mengonversi .nwd menjadi paket .svf menggunakan API resmi Autodesk saat ada internet, lalu menyimpannya ke IndexedDB atau mengekspornya menjadi satu file .nwdpack.zip agar dapat dibuka 100% Offline di laptop kantor yang terkunci (tanpa admin & tanpa internet).

1. Cara Konversi File .NWD & Export ke .ZIP (Saat Ada Internet)

  1. Buka menu APS Settings di kanan atas, masukkan Client ID dan Client Secret dari akun gratis aps.autodesk.com, lalu klik Test Connection.
  2. Buka tab Cloud .NWD di sidebar kiri, lalu Drag & Drop file .nwd Anda.
  3. Aplikasi akan otomatis mengunggah file, menjalankan translasi SVF, mem-parsing manifest.json di dalam 0.svf, dan mengunduh seluruh geometri (.pf, .pack), material, serta Property Database (objects_*.json.gz) ke IndexedDB.
  4. Pada tab Offline Library, klik Export .zip untuk mengunduh file tunggal NamaModel.nwdpack.zip (bisa disimpan ke Flashdisk).

2. Cara Buka Model 100% Offline di Laptop Kantor

  1. Buka URL GitHub Pages aplikasi ini satu kali di Chrome/Edge laptop kantor (atau klik tombol Install PWA & Cache Engine Offline di header atas).
  2. Setelah ter-cache, aplikasi dapat dibuka kapan saja meskipun Wi-Fi/LAN dimatikan total.
  3. Drag & Drop file .nwdpack.zip dari Flashdisk ke kotak Import Paket Offline (.zip) di tab Offline Library, lalu klik Buka 3D (Offline)!

3. Pintasan Kontrol 3D Navisworks Viewer

  • Orbit / Putar: Tahan Klik Kiri Mouse + Geser.
  • Pan / Geser: Tahan Tombol Tengah (Scroll Wheel) atau Shift + Klik Kiri.
  • First-Person Walk: Klik tombol Walk (WASD) di toolbar, lalu gunakan tombol keyboard W A S D untuk berjalan menyusuri pabrik/pipa dan Q / E untuk naik/turun.
  • Section Analysis & Measure: Gunakan ikon penggaris (Measure) dan potongan bidang X/Y/Z atau Box (Section Analysis) pada toolbar mengambang di bagian bawah kanvas 3D.
